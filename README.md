## 手动替换 GitHub Pages

在仓库根目录编辑 `index.html`：先下载本文件，再选 `...` → Upload files 或替换原文件并 Commit。页面通过 Pages 自动重新发布。GitHub连接写入权限不足时只能手工上传。

## 自动更新状态

ChatGPT每天09:00推送与此GitHub Pages尚未自动同步；需要另配置可信的内容发布流程。本版本不会伪称自动刷新。

## 维护与测试

保持现有单文件静态网站及哈希路由，GitHub Pages 项目子路径无需服务器重写。后续专题和设计修改继续在本仓库进行。

- 公开源码保留5个档案记录：2026-10-28待核验整理稿，以及10月24日至27日的4个待补录占位。占位不显示为正式刊期。
- 本机内容默认不参加网页导出。逐篇检查后勾选「允许随网页导出」，保存，再导出；未保存的编辑会阻止导出。已有网站档案自动保留。
- JSON备份包括本机全部内容，只供私人保管，不能提交到公开仓库。不要在公开编辑器中输入家庭医药私人资料；导出勾选是人为审阅记录，不是自动隐私识别或访问控制。
- 家庭私密站尚未建立。未来必须另用非公开仓库和受保护的托管环境；仅保护域名不能隐藏此公开仓库的内容。
- 没有新增每日新闻，也没有完成原稿逐条事实核验；每日09:00简报仍需人工导入。

本地测试（免费）：安装 Node.js，执行 `npm ci`、`npx playwright install chromium`、`npm test`。也可通过环境变量 `CHROME_PATH` 指向本机 Chrome。测试会启动临时本地HTTP服务，检查5种屏宽的全部主要路由、目录导航、档案完整性、导出授权和JSON字符往返。

GitHub Pages 继续使用已有 main 分支根目录部署。PR合并后应查看 Pages 构建结果并确认线上页面。测试脚本及开发依赖仅用于维护，网页运行无需安装依赖。
