# DAILY / TOPICS / ARCHIVE 与日报栏目映射

三个栏目只维护一份正文：`content/issues/YYYY-MM-DD.md`。`content/sections.js`是Node构建、校验和浏览器共同使用的解析器；`content/taxonomy.json`是10领域、9专题的唯一分类定义。`content/index.json`只保存摘要和机器生成的引用、状态，不另存专题正文。

- **01 DAILY｜今日概览**：最新published刊期的原文摘要、完整阅读入口及可展开全文。新格式包含世界速览、10领域、8–12条重点新闻、深度分析、9专题。
- **02 TOPICS｜九大专题**：从每一期的明确专题段落自动归类，按北京时间日期倒序，每页12篇并提供往期翻页。完整研究、来源和案例直接引用原段落，并链接回对应刊期位置。新一期追加引用，旧一期不消失。
- **03 ARCHIVE｜历史档案**：北京时间`YYYY-MM-DD`唯一刊期标识，独立Markdown文件；日期选择、全文搜索、较新/较早刊导航。已有文件不能被新稿覆盖。
- “待补录”“没有原文”“家庭私密版已隔离”是缺口/隔离记录，不能当作已完成的专题文章。既有基础教学案例继续保留，但不冒充当日研究。

## 后续ChatGPT报告的对齐方案

在现有任务配置可读取或由用户提供后，人工确认其栏目，并使用网站的9个稳定slug与公开版结构。合并艺术栏目只有在原文明确标出两部分时才自动拆分；未知标题不猜测归属。缺少外贸、案例或其他研究的稿件保留缺口；10领域中的相关新闻不能自动升级为专题研究。

网站独立API生成和手动导入遵循同一分类与校验，但不会修改当前ChatGPT定时任务，也不会自动拉取其对话内容。

## 医药家庭私密版

真正的家庭私人版必须另存于本公开仓库和站点之外的非公开存储/项目，不共用这里的正文、来源清单、索引、缓存或导出文件。

公开新版刊期的06专题仅允许固定说明：“本公开版不收录家庭医药私人资料；私密版独立存储，不参与公开归档。”它不会计作专题研究文章。公开摄取拒绝非public记录、未知私人元数据字段和该槽位的其他正文；部署按白名单生成，不复制任意content子目录。

自动规则不是通用隐私识别器。私人报告不要输入公开工作流、公开仓库或公开网页编辑器；Cloudflare Access也不能隐藏已经公开的Git历史。已有公开旧稿保持原文，其中没有家庭私人政策或经营数据。
